MY SERMON LIBRARY — FIRST VERSION

Included:
- Create, edit and delete sermons
- Categories and subcategories
- Bible references, tags, notes and EGW quotations
- PDF, Word, text and image attachments
- Search, favourites and light/dark mode
- JSON backup and restore
- Offline PWA support after first load

IMPORTANT DATA NOTE:
Sermons and attachments are stored in this browser on this device. Clearing browser/site data can erase them. Export a backup regularly and keep a copy somewhere safe. This first version does not sync automatically between devices.

HOW TO INSTALL ON ANDROID:
A Progressive Web App must be served from a secure HTTPS website to be installable and work offline reliably. Easiest free route:
1. Create a free account at GitHub.
2. Create a new public repository named my-sermon-library.
3. Upload all files from this folder to the repository's root.
4. In repository Settings > Pages, choose Deploy from a branch, select main and /(root), then Save.
5. Wait for GitHub Pages to publish the site. Open the published HTTPS address in Chrome on Android.
6. Chrome menu (three dots) > Install app or Add to Home screen.

USAGE:
- Add a sermon with the New sermon button.
- Add your own categories with + Category.
- Use Export backup regularly. To restore, use Restore backup.
- Attachments are stored inside the browser database and included in exported JSON backups.

This is a starter build. Test with a few sample sermons and export a backup before adding your full collection.
